MAX BOT — чистая тестовая версия для Bothost

1. В Bothost → Переменные:
   MAX_TOKEN = настоящий токен MAX-бота.

2. Не нужно:
   MAX_BOT_TOKEN
   BOT_TOKEN

3. Замените старый bot.py этим bot.py.

4. Перезапустите контейнер.

5. В логах должно быть:

=== MAX BOT START ===
Проверяю токен...
Токен принят MAX API.
Бот: ...
Бот запущен. Жду сообщения...

6. В MAX отправьте /start.

ВАЖНО:
В логах была ошибка CERTIFICATE_VERIFY_FAILED. Это не ошибка токена.
MAX официально требует доверенный сертификат Минцифры для platform-api2.max.ru.
Эта версия временно отключает проверку TLS-сертификата только для диагностики
и тестового запуска в Bothost. После того как бот заработает, сертификат лучше
настроить нормально и вернуть строгую проверку TLS.

Официальная документация MAX:
https://dev.max.ru/docs-api
