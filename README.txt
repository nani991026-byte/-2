ОБНОВЛЕНИЕ «СТРОИМ УЮТ» V2

Важное:
- используется существующая переменная Bothost MAX_TOKEN;
- API: platform-api2.max.ru;
- главная фотография: assets/main.jpg;
- если фотографии нет, бот всё равно запускается;
- кнопки сделаны через официальную inline_keyboard MAX API.

Установка:
1. Замени bot.py в GitHub этим файлом.
2. Создай папку assets.
3. Положи туда фотографию с именем main.jpg.
4. Перезапусти бота на Bothost.

Если .image_token уже появился после первой загрузки, бот повторно фото не загружает.
