# MAX BOT — чистая версия

## 1. Файлы

- bot.py — основной файл бота
- requirements.txt — зависимости
- README.txt — инструкция

## 2. Bothost

В разделе «Переменные» создай/измени:

MAX_TOKEN = ТВОЙ_НАСТОЯЩИЙ_ТОКЕН_MAX

Важно:
- MAX_TOKEN используется этим bot.py.
- MAX_BOT_TOKEN не нужен этому файлу.
- BOT_TOKEN не нужен этому файлу.
- Не вставляй токен в код bot.py.

После сохранения перезапусти бота.

## 3. Что должно произойти

В логах должно появиться:

=== MAX BOT START ===
Проверяю токен...
Токен принят MAX API.
Бот запущен. Жду сообщения...

Если токен неправильный, бот сразу покажет ошибку MAX API.

## 4. Проверка

Открой своего MAX-бота и отправь:

/start

Он должен ответить:

🏗️ Строим Уют

и показать кнопки:
📐 Рассчитать
📋 Услуги
📞 Связаться
ℹ️ О нас

Токен никому не отправляй и не публикуй.
